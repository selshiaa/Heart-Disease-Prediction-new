# Heart Disease Prediction

## About the Project

The Heart Disease Prediction project is a machine learning application that predicts the possibility of heart disease based on patient health data. It uses machine learning techniques to analyze medical attributes and provide a prediction.

The project aims to support early identification of potential heart disease risk through data analysis and machine learning.

## Objectives

- Predict the possibility of heart disease using patient health data.
- Apply machine learning techniques to analyze health-related information.
- Support early risk identification.
- Provide a simple and user-friendly prediction system.

## Technologies Used

- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn

## Features

- Patient health data input
- Data preprocessing
- Machine learning-based prediction
- Heart disease risk prediction
- Simple user interface

## How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/Heart-Disease-Prediction.git
```

### 2. Navigate to the Project Folder

```bash
cd Heart-Disease-Prediction
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
python app.py
```
